## 운항상태 — 배 안의 장비

[status/](status/index.html) — 운항상태 관제 화면의 카드 10장(0300~1200)이 가리키는 장비와 화면 밑그림 11장: 큰 그림, 동력 사슬, 조종권, 워터젯, 엔진, 변속기, 스러스트 베어링, 유압, 알람, 역할 정리, 관제 화면 밑그림.

## 만든 방식

각 페이지는 HTML 파일 하나다. 외부 라이브러리나 그림 파일 없이 아래 세 가지만 쓴다.

- **SVG**: HTML 안에 직접 쓴 도형으로 그림을 그린다.
- **CSS**: 밝은/어두운 화면, 휴대폰 너비에 맞춘다.
- **JavaScript**: 슬라이더·버튼을 만지면 그림이 바뀐다.

설명을 돕기 위한 단순한 그림이며, 실제 배의 구조와 수치는 배마다 다를 수 있다.

조종권 읽는 법 — 카드 두 장으로 "누가 쥐었나"를 가르기

02에서 "누가 핸들을 쥐었나"를 배웠다. 이번엔 관제 화면에 오는 칸으로 그걸 읽는다. 단서는 카드 두 장 — 0400 시스템 상태와 0500 외부 제어 인터페이스. 배 그림의 조종권 상자가 지금은 "우리 관제 / 다른 곳"만 말하는데, 더 나눌 수 있을까?

먼저 한 장으로 — 상황을 고르면 단서 칸에 불이 들어온다

상황

설명을 돕기 위한 그림이다. 값은 그림용이고, "오늘 실제 배"만 2026-10-29 로그 그대로다. 판단 순서(오른쪽)는 문서에 없어 그림에서 정했다 — 아래 확인할 것.

2. 판단 순서 — 위에서부터 먼저 걸리는 것

  1. 아무도 안 쥠 — 0400 주소가 254 → 주의(누군가 잡아야 함).
  2. 강제 로컬 — 0500 강제 로컬 true → 이상(현장이 막음, 우리가 못 가져옴).
  3. 명령 끊김 — 0500 요청 시간 초과 true → 이상(쥐었어도 명령이 안 감).
  4. 백업 — 0400 백업 중 true, 또는 상세 36 → 주의.
  5. 우리 관제 — 0500 제어 중 true → 정상.
  6. 가져올 수 있음 — 상세 16·17 → 정보(지금은 다른 곳이지만 넘겨받을 수 있다).
  7. 바뀌는 중 — 상세 33·34·64 → 주의(1초 뒤 다시).
  8. 다른 곳 — 못 가져옴 — 그 밖 → 이상. 이유는 상세 문구(예: 37 = 잠금, 40 = 스로틀 높음).

지금 앱은 5번과 8번만 쓴다("우리 관제 / 다른 곳"). 이 순서를 쓰면 배 그림의 조종권 상자가 "가져올 수 있음", "백업", "아무도 없음"까지 말할 수 있다.

3. 조타실·백업 장치를 이름으로 부를 수 있나

아직 못 한다. 0400 주소는 장치 번호일 뿐, 그 번호가 조타실인지 백업 패널인지는 설치마다 다르다(문서: "설치마다 달라 문서에 없음"). 실제 로그에는 176(0XB0), 208(0XD0), 0(0X0) 이 왔다. 이 배의 주소 표를 받으면 "다른 곳" 대신 "조타실"처럼 이름을 붙일 수 있다.

확인할 것 — 문서에 없거나 맞지 않는 것.
  • 오늘 실제 배: 제어 중 = 예 인데 제어권 상세 = 16(가져올 수 있음). 문서대로면 쥐었을 땐 상세 0(제어 중)이어야 한다. 둘 중 무엇을 믿나? 그림은 "제어 중"을 먼저 믿는다(5번이 6번보다 위).
  • 0400 주소 176 · 208 · 0 이 각각 어느 장치인가(우리 관제 · 조타실 · 백업 패널 …). 0 은 무엇인가.
  • 판단 순서(위 2장)는 그림에서 정했다 — 서버팀·제조사와 맞춰 본다.

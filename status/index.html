운항상태 개념 그림

운항상태 관제 화면의 카드 10장(0300~1200)이 배에서 무엇을 가리키는지 그림으로 이해하기 위한 모음.

  • 큰 그림 — 먼저 보기 배 부품을 누르면 자동차로 치면 무엇인지, 화면의 어느 카드에 나오는지. 보고서가 배에서 우리 앱까지 오는 길, 0300·조종권·백업 설명
  • 동력 사슬 엔진 → 변속기 → 베어링 → 워터젯, 옆의 유압 장치 — 장치 하나에 문제를 내면 "워터젯 가능"(1000)이 어떻게 바뀌나
  • 왜 있나 — 엔진에서 워터젯까지, 가운데 부품 (부품 보기 전에) 부품을 하나씩 빼 보면 왜 있는지 보인다(엔진·변속기·축·베어링·워터젯·유압). 카드 읽는 순서, 일별 역할. 기름 세 군데(변속기·베어링·유압)는 하는 일이 다르다. 자주 헷갈리는 질문
  • 조종권 우리 관제 · 현장 조타석 · 백업 · 자율운항 · 강제 로컬 중 누가 핸들을 쥐었나, 우리가 가져오려면 무엇이 막나 (0500·0400)
  • 부품 · 워터젯 바닥 흡입구 → 임펠러 → 노즐. 엔진 회전, 후진 덮개(버킷), 조향 노즐, 유압 끊김을 움직여 본다 (1000)
  • 부품 · 엔진 피스톤·크랭크축·시동 모터. 꺼짐 → 시동 → 예열 → 작동, 관제 명령이 엔진 제어기를 거쳐 가는 길, 현장 패널·셧다운 (0800·1100·0300)
  • 부품 · 변속기 원판 두 장이 붙으면 전진, 떨어지면 중립. 스로틀을 올린 채 옮기면 거부(38), 전진↔후진 바로는 거부(37) (0900·0300)
  • 부품 · 스러스트 베어링 물을 민 반동이 축 → 베어링 → 배 몸통으로. 오일 샘·과열·흐름 막힘, 베어링이 없다면? (0600)
  • 부품 · 유압 장치 전력 → 펌프 → 기름 → 밸브 → 피스톤이 노즐·버킷을 민다. 전력 끊김·새는 곳·기름 부족·과열 (0700)
  • 알람 — 상태가 아니라 일어난 일 온도계 vs 휴대폰 알림, 카드 한 장이면 앞 알람이 덮어써진다. 확인(사람이 봄)과 해소(원인 사라짐), 심각도 넷, 0400 요약 등 (1200)
  • 관제 화면 밑그림 — 배 그림 한 장으로 상태 보기 가짜 값으로 도는 밑그림. 위에 조종권·워터젯 가능·알람, 배 그림에 부품별 색과 값 하나, 힘의 줄·명령 줄이 끊긴 곳. 상황 7개(정상·N·현장 패널·베어링·유압·조타실·연결 끊김), 부품을 누르면 상세 카드
  • 배 그림 시안 — 셋을 나란히 놓고 고르기 앱에 넣은 배 그림을 정리할 시안 셋: A 요약 칸 + 배, B 배 하나에 다, C 줄 지도. 같은 가짜 값 상황 6개로 함께 바뀐다
  • 조종권 읽는 법 — 카드 두 장으로 "누가 쥐었나" 0400 주소·잠금·백업과 0500 열한 칸(제어권 상세)으로 우리 관제 / 가져올 수 있음 / 잠김 / 백업 / 강제 로컬 / 아무도 없음 / 명령 끊김을 가르는 순서. 오늘 실제 배 값이 문서와 어긋나는 곳
  • 칸별 나쁜 값 — 숫자는 누가 판단하나 숫자 기준은 문서에 없다. 대신 배가 상태 칸(OK · Low/High)으로 판단해 보낸다 → 색은 상태 칸, 숫자는 보여 주기만. 로그에 찍힌 Not fitted(실제 배) · FAIL(시험 값), 서버팀 질문
  • 엔진이 몇 대인가 — 한 대면 옆에서, 여러 대면 위에서 1대 · 2대 · 4대일 때 위에서 본 배와 오는 칸. 엔진마다 오는 건 0300 뿐, 나머지는 모름. 오늘 실제 배는 0300 이 안 왔다
